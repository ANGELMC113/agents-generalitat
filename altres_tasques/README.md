# Altres tasques

[Feu clic aquí per tornar a l'inici.](../README.md)

En aquesta carpeta hi ha diversos codis per accelerar l'ofimàtica amb Word.

S'han fet amb ChatGPT i Copilot i s'han provat per veure que funcionen correctament.

- [translator.py](./translator.py) serveix per traduir del català al castellà. Funciona en consola o processant un document Word.

- [cap_render.ipynb](./cap_render.ipynb) serveix per veure i desar les capçaleres (aprox.) de documents Word. Permet, d'una passada, comprovar que són correctes.

- [clustering_docx.py](./clustering_docx.py) serveix per fer clústers d'arxius Word a partir de les metadades.
